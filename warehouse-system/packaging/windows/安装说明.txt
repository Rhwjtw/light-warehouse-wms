轻仓 WMS V1.2 独立版

适用于 Windows 10/11 64 位电脑。
安装包包含后台、正式页面、Python 运行环境及独立 MySQL 8.4.9。
安装后在本机使用，不连接原服务器，不同步原系统的数据。
首次启动创建空数据库并设置管理员账号，不包含演示库存、真实业务数据或预置密码。

程序安装在当前 Windows 用户目录下。若电脑缺少微软 VC++ x64 运行库，安装过程中会请求管理员权限安装微软官方运行库。
建议至少保留 3 GB 可用磁盘空间，数据量和备份增长另计。

完成安装后，请双击桌面“轻仓 WMS 独立版”，在控制窗口设置管理员用户名和密码。
密码为 14～128 位，不得包含用户名。启动成功后浏览器自动打开登录页。
后续启动无需再次设置管理员。

数据保存在安装目录的 data 文件夹。不要删除、复制正在运行的 MySQL 数据目录或把数据放入同步盘。
通过控制窗口“备份数据”保存 SQL 和 SHA256 校验文件，并另存到其他磁盘。
关闭控制窗口会最小化到系统托盘；停止时点击“停止并退出”。不需要开机服务或防火墙配置。
电脑重启后，请再次双击桌面图标启动。

本版本默认只允许本机访问，使用本机独立端口，不会占用现有 80/3306 端口。
卸载保留 data 文件夹。当前安装包用于新安装，拒绝覆盖已初始化的数据库；已有独立版的升级和备份恢复须单独核对。

第三方许可证位于 mysql/LICENSE、python/LICENSE.txt 和 Python 包的 dist-info 文件夹中。
MySQL Community Server 为 GPL 软件，源代码可从 https://dev.mysql.com/downloads/mysql/ 和对应版本源码下载获得。
