# 安装与使用说明

## 访问已有系统

1. 向管理员获取系统地址和个人账号。
2. 电脑浏览器打开系统首页；手机浏览器打开系统地址下的 `/m`。
3. 登录后按自己的岗位权限办理业务。

手机相机扫码需要 HTTPS、相机权限及浏览器支持。账号的操作权限由系统角色控制。

## Windows 独立安装

支持 Windows 10/11 64 位。安装包由系统维护者另行提供，包含后台、前端页面、Python 和 MySQL 等运行组件。

### 首次安装

1. 运行安装程序，选择新的英文安装目录，例如 `D:\LightWarehouseWMS`。
2. 按安装向导完成安装。
3. 启动系统并设置首个管理员账号。
4. 由管理员创建实际使用的账号，维护单位、供应商、库位、原材料和成品档案。
5. 按实际业务录入 BOM、库存单据和生产单。

首次独立安装建立空数据库。安装包的功能以该版本为准，手机版网页需要相应版本的部署支持。

### 更新已有安装

使用适用于当前版本的安装升级包。更新前备份数据，停止系统，在原安装目录执行更新；不要先卸载、删除 `data` 或换到空目录代替升级。

### 日常启动与备份

通过桌面快捷方式启动系统，按控制窗口提示在浏览器中访问。备份文件需要妥善保管，恢复前确认目标安装和数据。

## 多人使用

系统部署到共享服务后，获授权的电脑与手机通过浏览器访问同一入口。独立安装到另一台电脑会建立另一套数据库，安装本身不会自动合并两套数据。
