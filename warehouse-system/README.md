# 轻仓 WMS

仓库管理 · 生产领料 · 手机仓储作业

轻仓 WMS 是面向仓储与生产场景的轻量级管理系统，将原材料、库位、生产单、BOM 配方和成品库存放在同一套系统中，覆盖从原料入库到生产领料、成品入库与出库的日常流程。

系统提供电脑版和手机版网页。电脑端适合资料维护、生产管理与统计查询；手机端适合在仓库现场查库存、出入库、上架、移库和盘点。

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 基础资料 | 原材料、成品、供应商、库位、单位与用户管理 |
| 原材料库存 | 入库、待上架、拆分上架、批次库存、库位库存与库存流水 |
| 仓储作业 | 原料出库、供应商退货、报废、移库及库位批次盘点 |
| 生产管理 | 多版本 BOM、生产单、用料计算、分次领料、补料、退料与完工登记 |
| 成品管理 | 普通入库、生产入库、按批次出库与库存查询 |
| 批次追溯 | 查询原材料批次、生产单与成品批次之间的关联 |
| 预警与统计 | 有效期预警、最低库存预警、首页统计与生产损耗统计 |
| 权限与记录 | 角色权限、操作日志及支持范围内的单据冲销 |

## 电脑版与手机版

**电脑版**提供完整的业务管理页面，适合维护档案和 BOM、管理生产单、办理车间领补退料、查看库存与损耗统计。

**手机版**提供库存和单据查询、原料入库与上架、原料和成品出入库、移库、盘点、二维码标签及相机扫码上架，方便现场作业。生产单、BOM 和车间领补退料使用电脑版页面办理。

两种页面使用同一套账号和权限，通过浏览器访问部署后的系统。

## 典型业务流程

原材料建档 → 入库 → 库位上架 → 创建生产单 → 领料与补退料 → 完工登记 → 成品入库 → 成品出库

原材料库存可以按批次和库位查看；生产单保留配方快照与实际用料，便于查询生产过程和损耗。

## 使用方式

- **访问已部署系统**：电脑浏览器打开系统首页；手机浏览器打开同一系统地址下的 `/m`。
- **Windows 独立安装**：安装包包含运行所需组件，适合在 Windows 10/11 64 位电脑上独立使用。新装建立空库，已有安装可按对应版本的升级流程保留数据更新。
- **源码部署**：后端与前端可以部署到同一服务入口，供获授权的电脑和手机访问。

本仓库提供源码。安装包另行提供，安装包包含的页面与功能以具体版本为准。使用步骤见[安装与使用说明](docs/INSTALL.md)。

## 技术栈

前端采用 Vue 3、Vite、Element Plus 和 Vue Router；后端采用 FastAPI、SQLAlchemy 与 Pydantic；数据库采用 MySQL，通过 Alembic 管理结构变更。

库存数量使用十进制计算，最多保留六位小数；库存操作关联单据和流水，并按角色检查操作权限。
